## 功能与界面契约

- 原位截图：框选后保持浮窗；语言、服务、原文/译文切换；自动重译；切换
  服务只重新翻译；候选服务不依赖普通结果卡片展开状态。
- DeepSeek 提问：保留卡片底部入口、展开输入、草稿、独立取消与 Markdown
  回复；Anki、Markdown、提问按钮按同一工具栏锚点顺序布局。
- 文本替换：保留用户所选服务、追加要求、逐 chunk receipt、部分失败提示，
  仅 Provider 首段之前的失败允许一次 fallback。
- 配置：只保留密码加密备份；语义 registry 对新增项显式分类；CLI 认证、
  生词内容、OCR 内容、缓存和机器路径不进入可迁移备份。
- 网络：所有新请求入口沿用 HTTPS 或精确 loopback HTTP；持有凭据的请求
  不向跨 origin 重定向；Anki 默认 loopback 地址符合该策略。
- 隐私：原位请求强制关闭明文 CLI 日志；Anki 操作日志只记录结果类别，
  不记录查询内容。导入上游功能不自动启用生词本或 Anki。
- 新用户文案同步 `en`、`es`、`ja`、`sk`、`zh-Hans`、`zh-Hant`。

## 工程执行与验证方法

- 生产适配由主执行者负责；测试执行者只修改 `EasydictTests/`，共享 Xcode
  工程和 String Catalog 由主执行者串行维护。
- 不同时运行指向同一个 DerivedData 的构建。保留已有缓存，避免运行旧产物。
- 每次提交检查 `git diff --check`、变更 Swift 的 SwiftFormat lint、JSON/plist。
- 必须先解决语义冲突，再以编译和测试检查无文本冲突的接口变化。
- 每次 push 前刷新远端 head，检查新增提交及 merge-resolution diff 的敏感信息；
  不将凭据、用户 OCR/提问原文、截图或本机绝对路径写进仓库。
- 不运行需要真实外部服务、CLI 登录或系统权限弹窗的完整测试目标；明确选择
  可隔离的 focused suites。每项验证记录命令类型、结果与边界。

## 风险与应对

- 2.23 与个人版预演有 12 个冲突文件，最新 dev 有 14 个。禁止整文件机械
  选择 ours/theirs；配置、流式取消、OCR、工具栏均逐段检查。
- 自动合并不证明安全策略仍覆盖新 transport，需要新增回归保护。
- 上游新增的账户组件安装流程不在本次真实登录验证范围内。
- 构建或测试失败时保留现场，修复后重新验证；不会将失败里程碑推送为完成。
